# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. You'll get a reply as soon as possible, and we'll agree on a disclosure date once a fix is ready.

Useful details include affected versions, steps to reproduce, and the impact you expect, for example on location privacy, group join tokens or mesh messages.

## Scope

- **In scope:** the Muster app code in this repository.
- **Mesh transport and encryption:** these are provided by the Offline Protocol SDK. Report SDK issues to the [Offline Protocol SDK](https://github.com/Offline-Protocol/offline-protocol-sdk) project. If you're not sure where a problem belongs, report it here and we'll pass it on.

## Supported versions

Only the latest release and the `main` branch get security fixes.
